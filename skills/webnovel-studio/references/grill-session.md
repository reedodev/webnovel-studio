# 기획 질문 세션 (선택 단계, 신작 기획 전용)

신작을 확정하기 전에 작가의 취향과 결정을 끈질기게 묻는 단계다. 방식은 공개된 grill 계열 스킬(질문을 결정 가지로 풀고, 질문마다 추천 답을 붙이는 인터뷰)에서 착안했고 문장은 복사하지 않았다.

## 언제 쓰나
- 작가가 신작 구상, 새 작품 기획, 기획 질문, "grill me"를 말하며 직접 시작을 요청했을 때만 쓴다. 스스로 켜지 않는다.
- 쓰지 않는 곳: 이미 연재 중인 작품의 회차 집필·검수, 사람이 없는 예약 연재 루틴, 이미 확정된 설정을 뒤집을 때(그럴 때는 작가에게 먼저 묻는다).
- 질문할 사람(작가)이 없으면 이 단계는 건너뛰고, 건너뛴 사실을 기획서에 적는다.

## 진행 방식
1. 시장 조사와 후보가 나온 뒤, 선정 전이나 선정 직후에 한다(`scenario-synthesis.md` 2번과 3번 사이, 또는 6번 산출물 전).
2. 한 라운드에 질문 3~5개를 번호를 붙여 묻는다. 질문마다 추천 답을 하나 붙이고, "네"라고만 해도 추천 답이 받아들여지게 쓴다.
3. 앞 질문의 답에 달린 질문은 다음 라운드로 미룬다. 작가가 "모르겠다"고 하면 그것도 답이다. 추천 답으로 확정하지 말고 미결정으로 적어 둔다.
4. 시장 자료나 기존 작품 목록처럼 찾아볼 수 있는 사실은 작가에게 묻지 않고 직접 찾는다. 작가에게는 결정만 묻는다.
5. 라운드가 너무 길어지면(질문이 계속 새로 생기면) 중간 요약을 보여 주고 이어 갈지 묻는다.

## 질문 가지 (필요한 것만)
- 주인공: 가장 원하는 것, 약점, 절대 하지 않을 선택
- 독자: 매화 다음 화를 누르는 이유, 처음 3화에서 받아야 할 보상
- 금지선: 쓰지 않을 소재, 수위, 이용 등급, 쓰고 싶지 않은 클리셰
- 이야기: 반전 한 줄, 결말 방향, 일찍 끝내면 안 되는 것
- 현실성: 하루 투입 슬롯과 분량, 80화 이상 소재가 마르지 않는지, 기존 연재와의 겹침
- 플랫폼: 노릴 사이트나 공모전, AI 사용 정책

## 끝내는 조건과 기록
- 끝: 모든 가지를 한 번씩 지났고, 말없이 가정한 것이 없을 때. 작가가 "이 정도면 됐다"고 확인해야 끝난다.
- 기록: 정한 것과 미결정인 것을 구분해 bible.md 초안 또는 기획서의 "작가 결정" 칸에 날짜와 함께 옮겨 적는다. 질문 세션 자체는 기록을 남기지 않으므로 옮겨 적지 않으면 사라진다.
- 확정 전에는 집필과 게시를 시작하지 않는다. 이 세션의 결과는 `scenario-synthesis.md` 7번의 사용자 확인을 대신하지 않는다.
- 질문이 많았다고 기획의 질이 보장되지 않는다. 답의 질이 결과를 정한다.
