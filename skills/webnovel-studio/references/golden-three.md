# 황금 3화 설계 (새 작품의 1~3화)

독자는 3화 안에 남을지 떠날지 정한다. 1~3화는 일반 회차보다 먼저, 더 촘촘하게 설계한다. 설정서(bible.md)와 첫 50화 구간 계약이 정해진 뒤에 한다.

## 세 화의 임무
- **1화:** 3쪽 안에 주인공이 누구인지 알게 한다. 첫 갈등이나 압박이 나온다. 핵심 능력이나 장치를 처음 발견하거나 켠다. 마지막에 구체적인 목표 하나(내일 해야 할 일)를 남긴다. 이 셋 중 하나라도 빠지면 다시 설계한다.
- **2화:** 눌려 있던 상황이 풀리는 첫 통쾌함. 능력을 실제로 한 번 쓴다. 쓸 때 들어가는 것(입력, 비용, 한계, 대가)을 장면으로 보여 준다. 능력 창이나 알림만 보여 주고 끝내지 않는다.
- **3화:** 첫 승리와 정산. 상대가 누구인지, 무엇을 치르고 무엇을 얻었는지, 바깥 사람들이 어떻게 반응했는지를 쓴다. 끝에 더 큰 제한이나 다음 단계의 단서를 건다.

## 세 화 안에 하지 않는 것
- 세계관을 설명하는 단락(정보는 행동 중간에 한 줄)
- 주인공의 내면 독백이 두세 문단을 넘는 것
- 갈등 없는 일상 장면이 300자(영문 60단어)를 넘는 것
- 설정서에 없는 새 능력, 아이템, 규칙을 갑자기 만드는 것
- 반응을 설명으로 전하는 것(사람들의 말과 몸짓으로 보여 준다)

## 복선
3화 안에 최소 둘을 심는다. 하나는 10~20화 안에 회수할 짧은 것, 하나는 50화 이상 뒤에 회수할 긴 것. 둘 다 ledger.json의 plants에 회수 예정 화수와 함께 적는다.

## 화별 미세 설계표 (쓰기 전에 채운다)
```
## N화 제목 (이 화의 감정 위치)
- 이 화의 임무 (독자 마음에 만들 감정 한 가지):
- 첫 장면 방식: 행동 중간에서 시작 / 이상한 상황 / 충격 대사 / 카운트다운 / 중대한 발견 / 위기 / 수수께끼 / 중대한 선택
- 앞 화 끝을 어떻게 이어받는가 (1화는 "없음"):
- 앞 20%의 끌어당김 (갈등, 압박, 이상, 정보 차이, 행동 목표):
- 장면 비트 (글자 수 구간): 
  1. (0~800자) 
  2. 
- 핵심 대사 원문 (인물별 1줄 이상, 몸짓 포함):
- 마지막 장면 그림 한 줄 (구체적으로. "여운" 같은 말 금지):
- 훅 종류: 폭로 / 위기 / 끝나지 않은 행동 / 정체·입장 반전 / 양자택일 / 수상한 단서 / 시간 제한 / 약속·위협 / 말 속 뜻 / 울림 / 강화 예고 / 갈등 예고
- 쓰면 안 되는 것 2개 이상 (예/아니오로 판단 가능하게. "속도 주의" 말고 "세계관 설명을 300자 넘기지 않는다"):
- 꼭 해야 하는 것 1개 이상:
```

## 3화 점검표 (각 칸 있음/없음으로 적는다)
주인공 파악(1화), 첫 3문단 안의 끌어당김(1~3화), 마지막 훅(1~3화), 통쾌한 장면(1~3화), 장르 약속이 선 것, 능력의 규칙과 대가가 구체적인가, 대사가 원문으로 정해졌는가, 복선 둘 심었는가, 금지선이 판단 가능한가.

## 웹소설 한국판 기준에 맞출 때
- 1화는 공모전·플랫폼의 최소 글자 수(예: 공백 제외 3,000자)를 확인한다. 작품별 workflow.md의 수치를 따른다.
- 악역은 입체적일 필요 없이 미워할 만하면 된다. 주인공이 이기는 것을 보고 싶게 만든다.
- 주인공의 성격은 행동으로 굳힌다. "차가운데 사실은 다정하다"는 속마음 설명 말고 급한 순간의 행동 하나로 보여 준다.
